Autonomous Vehicle Intercommunication Safety Agent System

Simulated vehicles share hazard reports. Four cooperating agents verify them, warn the vehicles nearby, learn from feedback, and explain every decision with cited evidence.

    01 · Why

    The problem

    An autonomous vehicle normally decides using only its own sensors. In dense fog, a vehicle cannot see a stopped truck 500 m ahead, even though another vehicle that is already beside the truck can.

    This system is a shared safety intelligence layer. It collects reports from the fleet, checks whether they are reliable, and sends warnings to the vehicles that need them.

    A single prompt is not enough. The agents must link reports that arrive at different times, track confidence, work out who is on an affected path, retract a hazard when the road is clear, and remember outcomes.

    02 · How

    How the four agents work

    Each vehicle report is one run through a LangGraph workflow. The agents hand typed messages to each other, and every step is written to an execution trace.

    1

    Hazard Analysis Agent

    Classifies the hazard, turns “500 m ahead” into a position on the road, and matches it to hazards already being tracked.

    2

    Verification Agent

    Applies the confidence rules and decides: verified alert, caution advisory, wait for evidence, or resolve.

    3

    Alert Agent

    Finds the nearby vehicles that need the warning and sends them the message.

    4

    Research & Memory Agent

    Retrieves similar past incidents from a vector database, and saves what it learns.

    ⇄ Verification and Research & Memory also exchange a two-way history request and reply for new hazards.

    03 · Learning

    It remembers

    When a hazard is resolved, the outcome is written to long-term memory and added to a vector database (ChromaDB). When a new hazard appears, the Research & Memory Agent retrieves similar past incidents, a technique called retrieval-augmented generation (RAG).

    Each similar past incident that was confirmed adds 0.05, and each that was a false report subtracts 0.05, capped at ±0.15 in total. If retrieval fails, Verification scores on the rules alone, so the vector database can never block a warning.

    04 · Oversight

    Humans stay in the loop

    If at least two vehicles confirmed a hazard, another reported it clear, and that conflict has lasted 2 minutes without being settled, the agents stop requesting observations. The Alert Agent sends one escalation to a human fleet operator.

    It is a retry limit followed by failover to a person, applied to the agents’ observation loop.

    05 · Results

    Evaluated

    On the project’s seven scenarios (25 reports), the hybrid graph produced 0 false warnings and made the same decisions in 25 of 25 cases. With no history request (one-way), it produced 1 false warning and matched in 20 of 25. With no verifier, it produced 1 false warning and matched in 12 of 25.
